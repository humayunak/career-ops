# skill-form-answers — Application Form & Interview Answers

Trigger: user selects option [6] or [7] at Approval Gate, or pastes form questions.

## For application form questions
User pastes the questions. For each:
1. Identify question type (behavioral / technical / motivational / situational)
2. Pull most relevant experience from master-profile.md
3. Write answer:
   - Behavioral → STAR format (Situation, Task, Action, Result)
   - Technical → direct, specific, with examples
   - Motivational → genuine, role-specific, no generic lines
   - Word/char limit → respect it, trim to fit

Output as numbered Q&A list. User reviews and edits before submitting.

## For interview prep
Generate 10 likely interview questions based on JD + profile gaps.
For each: suggested answer using STAR where applicable.
Save as `interview-prep_[company].md` to Google Drive application folder.
