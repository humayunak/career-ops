# skill-cover-letter — Cover Letter Generator

Trigger: user selects option [3] or [7] at Approval Gate.

## Structure

**Opening (2-3 sentences)**
- Name the role + company specifically
- One strong hook — most relevant credential or shared mission

**Body paragraph 1 — Experience match**
- Connect 1-2 specific experiences directly to key JD responsibilities
- Use a concrete metric

**Body paragraph 2 — Unique value**
- What you bring that a generic candidate doesn't
- Reference something specific about the company (their product, recent news, mission)

**Closing (2-3 sentences)**
- Express genuine interest
- Clear call to action

**Tone:** Confident, direct, human. No clichés ("passionate", "team player", "hard worker" without evidence).

## Output
- Format: HTML artifact (same design system as resume template) OR markdown if user prefers
- Filename: `[kebab-role]-cover-letter_[company].html`
- Save to Google Drive: same application folder as resume
- Update Notion record with Cover Letter URL
