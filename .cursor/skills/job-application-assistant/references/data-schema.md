# Data Schema Reference

## master-profile.md sections

Required sections (in order):
1. Contact (name, email, phone, LinkedIn, location)
2. Summary (primary role focused, 3-4 sentences)
3. Target Roles (primary / secondary / tertiary)
4. Experience (each role: company, title, dates, 3-6 bullets with metrics)
5. Projects (name, description, tech stack, outcome/metric)
6. Skills (grouped by category)
7. Education
8. Certifications
9. Preferences (from job-preference.md — remote, salary, industries)

## job-preference.md sections

1. Role preferences (ranked)
2. Work arrangement (remote/hybrid/onsite)
3. Salary target
4. Company preferences (size, industry, culture)
5. Avoid list (roles, industries, company types)
6. Timeline
7. Additional context

## linkedin-profile.md sections

Mirror LinkedIn structure exactly:
1. Header (name, headline, location)
2. About
3. Experience (reverse chrono)
4. Education
5. Skills & Endorsements
6. Certifications
7. Recommendations (optional)

_This file is the source of truth. master-profile.md must not contradict it._
