# Copywriting Prompt Patterns

Frameworks and templates for persuasive, marketing, and content writing prompts.

---

## Core Copywriting Frameworks

### AIDA (Attention → Interest → Desire → Action)
Best for: Sales pages, email campaigns, ads

```
You are an expert direct-response copywriter.

Write {{CONTENT_TYPE}} for {{PRODUCT_OR_SERVICE}} using the AIDA framework:

- **Attention**: Hook that stops the scroll (1-2 sentences)
- **Interest**: Why this matters to the reader (2-3 sentences)
- **Desire**: Paint the transformation / outcome they'll get (3-4 sentences)
- **Action**: Clear, compelling CTA

Target audience: {{AUDIENCE}}
Key benefit: {{MAIN_BENEFIT}}
Tone: {{TONE}} (e.g. professional, conversational, urgent)
```

### PAS (Problem → Agitate → Solution)
Best for: Email subject lines, Facebook ads, cold outreach

```
Write {{CONTENT_TYPE}} using the PAS copywriting formula for {{PRODUCT_OR_SERVICE}}.

- **Problem**: Name the pain the audience feels
- **Agitate**: Deepen the pain — what happens if it's not solved?
- **Solution**: Present {{PRODUCT_OR_SERVICE}} as the answer

Target audience: {{AUDIENCE}}
The core problem they have: {{PROBLEM}}
What our solution does: {{SOLUTION}}
Desired CTA: {{CTA}}
Word limit: {{WORD_COUNT}}
```

### BAB (Before → After → Bridge)
Best for: Transformation stories, testimonials, landing pages

```
Write {{CONTENT_TYPE}} using the BAB (Before-After-Bridge) framework.

- **Before**: Describe the reader's current painful situation
- **After**: Paint a vivid picture of their life after the solution
- **Bridge**: Introduce {{PRODUCT_OR_SERVICE}} as the bridge

Product/Service: {{PRODUCT}}
Audience: {{AUDIENCE}}
Core transformation: From {{BEFORE_STATE}} to {{AFTER_STATE}}
```

### FAB (Features → Advantages → Benefits)
Best for: Product descriptions, spec sheets with emotional appeal

```
Write a product description for {{PRODUCT}} using FAB:

For each key feature, complete:
- **Feature**: What it is
- **Advantage**: What it does better than alternatives
- **Benefit**: What the customer gains / feels / achieves

Features to cover:
- {{FEATURE_1}}
- {{FEATURE_2}}
- {{FEATURE_3}}

Target buyer: {{BUYER_PERSONA}}
Tone: {{TONE}}
```

## Specific Content Types

### Facebook / Instagram Ad
```
Write 3 variations of a {{PLATFORM}} ad for {{PRODUCT_OR_SERVICE}}.

Each variation should:
- Start with a pattern-interrupt hook (question, bold claim, or stat)
- Be {{WORD_COUNT}} words max
- Have a clear CTA: {{CTA}}

Audience: {{AUDIENCE}}
Key pain point: {{PAIN_POINT}}
Unique selling proposition: {{USP}}
Tone: {{TONE}}

Format:
**Variation 1:** [Hook style: Question]
[Ad copy]

**Variation 2:** [Hook style: Bold claim]
[Ad copy]

**Variation 3:** [Hook style: Statistic/Social proof]
[Ad copy]
```

### Email Subject Lines
```
Generate 10 email subject lines for an email about {{EMAIL_TOPIC}}.

Mix of styles:
- 3 curiosity-gap subject lines
- 3 benefit-driven subject lines
- 2 urgency/scarcity subject lines
- 2 personalized/direct subject lines

Audience: {{AUDIENCE}}
Goal of the email: {{EMAIL_GOAL}}
Keep each under 50 characters.
```

### Cold Outreach Email
```
Write a cold outreach email for {{SENDER_ROLE}} reaching out to {{TARGET_ROLE}} at {{COMPANY_TYPE}}.

Goal: {{GOAL}} (e.g., book a call, get feedback, offer service)

Rules:
- Subject line: Under 7 words, no clickbait
- Opening: Reference something specific about them (use {{SPECIFIC_DETAIL}})
- Value prop: One sentence, concrete benefit
- Ask: Single, low-friction CTA
- Length: Under 120 words

Tone: {{TONE}}
```

### Landing Page Hero Section
```
Write the hero section copy for a landing page for {{PRODUCT_OR_SERVICE}}.

Include:
1. **Headline** (under 10 words — the core promise)
2. **Sub-headline** (1-2 sentences expanding on the promise)
3. **3 bullet points** (key benefits in "so you can..." format)
4. **CTA button text** (2-4 words, action-oriented)
5. **Social proof line** (e.g., "Trusted by 5,000+ teams")

Target audience: {{AUDIENCE}}
Core promise: {{PROMISE}}
Primary differentiator: {{DIFFERENTIATOR}}
```

### Product Description (eCommerce)
```
Write a product description for {{PRODUCT_NAME}} to be used on {{PLATFORM}}.

Specs:
{{PRODUCT_SPECS}}

Structure:
1. Opening hook (1 sentence — lead with the benefit, not the product)
2. Problem it solves (1-2 sentences)
3. Key features → benefits (bullet format, max 5)
4. Who it's for (1 sentence)
5. CTA

Tone: {{TONE}}
Max length: {{WORD_COUNT}} words
```

### Social Media Post (LinkedIn / Twitter / Instagram)
```
Write a {{PLATFORM}} post about {{TOPIC}} for {{BRAND_OR_PERSONA}}.

Goal: {{GOAL}} (educate / entertain / convert / build trust)
Tone: {{TONE}}
Max length: {{CHARACTER_LIMIT}}

Include:
- Strong opening line (no "I'm excited to share" openings)
- Core message
- {{INCLUDE_HASHTAGS: yes/no}}
- CTA or engagement question at the end

Write 2 variations.
```

## Tone & Style Reference

When the user specifies a tone, apply these characteristics:

| Tone | Characteristics |
|---|---|
| **Professional** | Clear, confident, no slang, third-person optional |
| **Conversational** | First/second person, short sentences, contractions OK |
| **Urgent** | Present tense, scarcity language, action verbs |
| **Witty/Playful** | Puns OK, light humor, unexpected angles |
| **Empathetic** | Acknowledge pain, "you're not alone", warm language |
| **Bold/Direct** | No hedging, strong claims, minimal qualifiers |
| **Authoritative** | Data-backed, expert voice, formal structure |
