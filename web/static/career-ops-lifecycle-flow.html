Career-Ops — Main workflow

Same story as the Web Commands panel and dashboard: discover roles → evaluate in Cursor → apply (you submit). Web = read and triage · Cursor = write reports and PDFs.

You

  • • Paste URLs and JDs in Cursor
  • • Review score and PDF before applying
  • • Click Submit on the employer site
  • • Update status when recruiters reply

Cursor agent

  • • Writes reports/, output/, apply-drafts/
  • • Updates career-ops.db via db.mjs
  • • Playwright for live job pages
  • • Never auto-submits applications

Web UI (:8793)

  • • Inbox · Applications · Reports
  • • Copy prompts · View apply drafts
  • • Refresh to see agent output
  • • Does not run evaluations itself
